# TPS54331DR / D / SOIC8 手工修正规格

这些数据用于说明本次如何纠正焊盘，不是适用于所有SOIC8器件的通用模板。来源是仓库SLVS839F手册第35页。DDA裸露焊盘版本不适用。

在封装编辑器将单位切换为mm，以封装中心为原点：

| 焊盘编号 | X / mm | Y / mm |
| --- | --- | --- |
| 1 | -2.700 | +1.905 |
| 2 | -2.700 | +0.635 |
| 3 | -2.700 | -0.635 |
| 4 | -2.700 | -1.905 |
| 5 | +2.700 | -1.905 |
| 6 | +2.700 | -0.635 |
| 7 | +2.700 | +0.635 |
| 8 | +2.700 | +1.905 |

所有焊盘均为顶层矩形贴片焊盘、无孔、旋转0°，铜尺寸X方向1.55mm、Y方向0.60mm。推荐阻焊向外扩展0.07mm；推荐锡膏开口1.50×0.55mm，对应每边内缩0.025mm。最终按制造工艺复核。

原实测使用已核对签名的嘉立创EDA API修改8个测试焊盘并保存。编辑器按0.1mil量化，读回铜尺寸61×23.6mil、X为±106.3mil、Y为±75/±25mil。换算后与上述名义尺寸有约微米级差异。

在原生焊盘属性或焊盘列表中输入以上编号、坐标、尺寸，逐项确认后保存。若版本提供多选同类属性编辑，可批量设置相同尺寸；否则逐个修改。不要把第34页的物理引脚总跨度6.20mm作为焊盘排中心距。

还必须修正丝印：原生成的两条竖边压在焊盘内侧，需移动、断开或重画，并检查丝印线宽及与阻焊开口的间距。按实际工艺规则决定最终位置，不在这里给未经验证的通用间距值。随后检查庭院、装配层和1脚标记；本次未完成这些生产审核。

修改外部封装库后，已有工程中的模板可能保持旧值。应在工程内更新库，核对原理图器件关联和PCB实际焊盘，不能仅保存外部库就认为工程已更新。[官方工程库行为](https://prodocs.lceda.cn/cn/faq/editor/)
