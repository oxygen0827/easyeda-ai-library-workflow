## 输入和操作

使用现有SLVS839F家族手册，目标明确为TPS54331DR、D/SOIC8、无裸露焊盘。原始资料位于内部资料目录（公开副本为`TPS54331-family-SLVS839F.pdf`）；家族手册同时含D/DDA，不能以存储目录后缀决定目标封装。第4页为引脚，第34页为D机械图，第35页为推荐焊盘图。测试资料均在仓库根目录。

## 平台应实现的便捷流程

1. 上传/选择手册，只要求用户确认完整型号与封装后缀；自动筛选引脚、机械图和推荐焊盘图，保留页码证据。
2. 提取为结构化引脚表和封装参数；自动检查脚数、编号唯一性、D/DDA等变体、必填尺寸和单位。缺项停止生成，不能静默使用默认值。
3. 用确定性模板生成焊盘；优先厂家land pattern，禁止把物理引脚宽长直接当焊盘。检查丝印/焊盘、阻焊、锡膏和庭院。
4. 自动创建Symbol、Footprint、Device并建立编号映射，给出差异与预览；工程师一次集中审核，不再逐个操作传统库窗口。
5. 审核后生成不可变本地修订与原生包，自动放入工程和更新PCB。复用已有通用封装时只审核新符号及映射。

本次样本说明按需建库值得做，但不能照搬当前扩展的UI或把“创建成功”当工程正确性。后续应先修正模板/校验，再扩展更多封装样本；本次没有把该流程接入平台或部署生产。
